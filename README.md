# world

**定位**：可暂停守城 RTS + 边疆经营（汉匈边塞，屯田御胡）

- 商店首行（对标钩）：《Frostpunk》式的经营抉择 × 《三国志12》式的可暂停攻城战
- 宣传语（机制钩）：你的运输线，就是匈奴的劫掠目标

白天派工种田、铺运输线、收商税、接皇帝任务；烽燧报警，收保平民、抉择城门开闭——你的粮道就是匈奴的劫掠目标。总攻之夜：指挥步、弓、工兵，齐射、火油、檑木，抓窗口出城拆冲车。匈奴不是血厚的小怪：诱敌、伏击、劫粮道，利则进、不利则退。**守住城，也要养活人——声望归零，同样败北。**

设计文档见 `game-design/`（**00-总纲**：定位与首发范围冻结；01~07：经济/战斗/人口声望/切片/仓储/RTS/科技任务）。
