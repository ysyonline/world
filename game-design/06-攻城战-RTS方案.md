## 1. 设计总纲：一场攻城战在干嘛

**【核心循环】**（战中 3~8 分钟，待原型验证）：

```
敌多路逼近 → 远程消耗（弓兵齐射骑射手与登城步兵）
  → 器械抵城（箭矢刮痧！压力陡增）
  → 决断点：步兵出城拆器械（冒被铁骑截杀的风险）
  → 门血告急 → 堵门/退守预备位
  → 重弩点杀高价值目标（弩骑、井阑射手）
  → 击退 or 城破——门破≠败，匈奴涌入城内才败（步兵堵门洞=最后窗口）
```

**【玩家在战中的五个决策点】**（与 02 §7 一致——防枯燥的核心：每 30~60 秒必须有一次有意义的操作）：
1. 各墙段/各门的远程火力分配（哪里堆弓兵）
2. 齐射时机（爆发技能，装填期是真空）
3. 步兵出城窗口（拆器械 vs 被铁骑吃）
4. 重弩点杀目标选择（弩骑？井阑射手？）
5. 预备队调动（哪门告急补哪门）

**【验证指标】**：单场战斗玩家有效操作次数 ≥10；暂停使用占比（太低=节奏太松，太高=信息过载）；各兵种击杀占比（揪出废兵种）；破门位置分布（总是同一门=布防无意义）。全部待原型验证。

## 2. 战场结构：前门/后门与墙段（含侧翼天险）

> 史据锚点：汉边城/障塞规模小——疏勒城遗址（耿恭守城处，新疆奇台石城子）实测东西 280 米 × 南北 380 米，「北、西面筑墙，东、南以深涧为屏障」——**不是每面都有门、每面都要守**，天险面不设防是史实常态。

- 城为四面，每面由若干**墙段**组成；**门是特殊墙段**：耐久低于墙、可被撞开、通行口。
- **门数定死两座（2026-10-06 定案，取代原「2~4 门关卡变量」）**：前门（正门）与后门（便门）；**城左右两侧为天险面**（深涧/峭壁），不可进攻、不可布防、不设门。
- 门与墙的耐久继承 02 v2 模型：独立血条、累积不自动恢复；修门耗**土+木**（土多木少，见 01 §4.3）。
- 进攻面规则（v0.2 定案 + 10-06 收敛）：**骚扰波不攻城**（不撞门不拆墙；但城门开启时铁骑可经门入城抢掠，见 §7）→ **总攻只从前/后两个方向来**，AI 随机三选一：**猛攻前门 / 猛攻后门 / 前后齐攻**（齐攻低概率 = 最坏情况）。
- **每个方向的攻击点 = 2 个**：该方向的门 + 门侧一段**可攀墙**（云梯步兵登城职能保留于此）。全域共 **4 段布防**：前门 / 前侧墙 / 后门 / 后侧墙。侧翼天险面之外不再设攻击点。

## 3. RTS 核心规则（RTK12 式）

| 项目 | 规则 |
|---|---|
| 时间 | 即时制；速度 暂停 / 1x / 2x；**暂停中可下达全部指令**（暂停 = 免费思考，RTK12 的核心手感） |
| 操控粒度 | 以「队」为单位（一营一队），不操控单兵；我方队数 3~5 支（步兵队 / 弓兵队 / 工兵队 / 预备队），敌以「队」为编队 |
| 指令集 | 移动 / 驻防（上墙段、堵门、出城列阵）/ 集火指定目标 / **齐射**（技能）/ 撤入城内 |
| 齐射 | 弓兵队爆发技能：短时间高密度射击，之后进入长装填（真空期）。史据：晁错《言兵事疏》「材官驺发，矢道同的，则匈奴之革笥木荐弗能支也」——齐射是汉军克制匈奴皮甲木盾的国家队战术 |
| 熟练度 | 沿用 02 已实装的个体熟练度：战力系数 0.6+0.4×prof；溃逃锚 prof 低端；杀敌积累老兵 |
| 俯仰修正 | 城上射城下 ×1.2，城下射城上 ×0.7（占位）。史据：《言兵事疏》「平陵相远，川谷居间，仰高临下，此弓弩之地也」——居高临下是弩的法定地利 |

> ~~战中资源：箭矢存量~~ **已取消（v0.2 用户定案）**：剑与箭非消耗品、不计入。战前经济准备在战中的兑现，由**檑木/火油/重弩的器械储备**（工匠坊产物，耗木耗铁）承担。

## 5. 器械克制规则（用户核心思路落地）

**【伤害结构】**（全部占位，待原型验证）：

| 攻击方 → 目标 | 有生力量（步/骑） | 器械（冲车/云梯/井阑） |
|---|---|---|
| 普通箭（弓兵） | 基准伤害 | **×0.1 装甲减免**（蒙革铁皮，箭矢刮痧） |
| 重弩（工兵操作） | 高伤（点杀弩骑/井阑射手） | ×0.3（重矢可伤结构，但效率低） |
| 火油（工兵城头倾倒） | 基准+灼烧 | **点燃 DoT，器械杀手①**（火箭设定已取消，统一为火油） |
| 檑木（工兵操作） | 城下范围杀伤 | **×2，器械杀手②**（站位被压在城下时） |
| 步兵出城 | 对步兵均势，对铁骑劣势 | **拆除 DPS 基准，器械杀手③（最可靠）** |

**【克制环闭环】**：
- 敌器械不怕箭 → 逼步兵出城
- 出城步兵被铁骑克制 → 出城前须先用弓兵/齐射压制铁骑 → **出城是一个"先创造窗口、再执行"的两步决策**，不是无脑操作
- 火油/檑木/重弩/近战四路反器械各有盲区（DoT 慢 / 只打城下 / 效率低 / 要冒险出城）→ 无一万能

> 史实注脚：守城方对付蒙革器械，史上确有「近战出城毁械」与火攻两路——《墨子·备城门》通篇即此思路；另《墨子》载**塞门刀车**（门破后以刀车塞门），可作为门破后堵门窗口的史实升级版，留待定清单（§9）。

## 6. 匈奴 AI 战术性格（"不枯燥"的另一半来源）

> 全部出自《史记·匈奴列传》原文性格描写，让敌人"像匈奴"而不只是"血多的小怪"：

| 性格 | 史据原文 | AI 行为落地 |
|---|---|---|
| 诱敌 | 「善为诱兵以冒敌」；白登之围「匿其精兵，见其羸弱」 | 小股游骑城下游走佯攻，诱玩家出城追击 → 埋伏铁骑杀出。**出城追击有真实陷阱** |
| 不羞遁走 | 「利则进，不利则退，不羞遁走」 | 劣势即撤，不硬拼；铁骑入城**抢满载荷即走、不占城** → 波次式节奏 |
| 逐利 | 「所得卤获因以予之，得人以为奴婢」 | 骚扰期以抢掠杀掳为目标：城外毁田劫粮道，城门开则铁骑入城掠粮抢钱（单次上限占位：粮 = 库存 10%、钱 = 15%） |
| 多路分进 | 白登之围「西方尽白马，东方尽青駹马，北方尽乌骊马，南方尽騂马」 | 总攻**两个方向**由不同编队负责，**各方向兵种配比不同**（如前门冲车+铁骑、后门井阑+弩骑+云梯步兵登门侧墙），视觉可用马色区分编队（致敬白登四色）。注：RTS 原型中「乌编队爬东墙」为旧地图脚本，整合关卡迁移时改为**爬门侧墙** |
| 秋高马肥 | 「秋，马肥，大会蹛林，课校人畜计」 | 正式版钩子：总攻时间锚定秋季 → 与经营线的农时/仓储节奏咬合（联动 01 §10 农时议题） |

## 7. 波次结构（v0.2 定案：两层）

| 波次 | 内容 | 设计意图 |
|---|---|---|
| **骚扰波**（多波） | **不攻城**（不撞门不拆墙）。城外：游骑毁田、杀平民、劫粮道、烧烽燧；**城门开启** → 小股铁骑入城杀人、掠粮、抢钱（单次上限占位：粮 = 城内库存 10%、钱 = 15%），**抢完即走**；**城门关闭** → 不进城，只在城外活动 | 拷问战备余量 + 城门开闭决策（关门=锁死城外自己人）；预警 = 收保+关门的窗口 |
| **总攻**（最终波） | 全谱系+器械齐上（冲车/井阑/云梯步兵）；AI 随机：**多门齐攻 或 猛攻一门**；**门破≠败，匈奴涌入城内=败**（门破后步兵堵门洞=最后窗口） | 经济+军事总检验；四色分进多门同压 |

## 8. 与切片的关系（落地路径建议）

1. **切片不动**：自动结算版守城战继续验证经济闭环与数值咬合（04 §9 纪律不破）。
2. **RTS 单独立项做轻量原型**：剥离经营层，只做一张城墙地图 + 3 支我方队 + 预设敌波次，验证「暂停下指令 + 出城拆器械 + 重弩点杀」三个决策点是否成立——原型优先，乐趣验证了再谈整合。
3. 原型验证指标见 §1 验证指标；数值全部沿用「集中配置、一处调参」纪律。
