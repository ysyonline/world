## 1. 设计总纲：一场攻城战在干嘛

**【核心循环】**（战中 3~8 分钟，待原型验证）：

```
敌多路逼近 → 远程消耗（弓/弩齐射骑射手与步兵）
  → 器械抵城（箭矢刮痧！压力陡增）
  → 决断点：近战出城拆器械（冒被突骑截杀的风险）
  → 门血告急 → 堵门/退守预备位
  → 敌指挥官暴露 → 重弩点杀 → 敌编队溃散
  → 击退 or 破门
```

**【玩家在战中的五个决策点】**（防枯燥的核心——每 30~60 秒必须有一次有意义的操作）：
1. 各墙段/各门的远程火力分配（哪里堆弓兵）
2. 齐射时机（爆发技能，装填期是真空）
3. 近战出城窗口（拆器械 vs 被突骑吃）
4. 重弩点杀目标选择（指挥官？井阑射手？器械操作手？）
5. 预备队调动（哪门告急补哪门）

**【验证指标】**：单场战斗玩家有效操作次数 ≥10；暂停使用占比（太低=节奏太松，太高=信息过载）；各兵种击杀占比（揪出废兵种）；破门位置分布（总是同一门=布防无意义）。全部待原型验证。

## 2. 战场结构：多门与墙段

> 史据锚点：汉边城/障塞规模小——疏勒城遗址（耿恭守城处，新疆奇台石城子）实测东西 280 米 × 南北 380 米，约 14 个足球场大，「北、西面筑墙，东、南以深涧为屏障」——**不是每面都有门、每面都要守**，天险面不设防是史实常态。

- 城为四面，每面由若干**墙段**组成；**门是特殊墙段**：耐久低于墙、可被撞开、通行口。
- **门的数量做成关卡配置（2~4 门）**，不是定死四门：首关 2 门（教学），后期 3~4 门 + 一面天险（深涧/峭壁，不可进攻但也不可布防）。
- 门与墙的耐久继承 02 v2 模型：独立血条、累积不自动恢复、修门耗钱木。
- **轒輼掘墙**（§5）可在非门墙段制造临时缺口 → 门的数量不等于实际进攻面数，防线会被"挖大"。
- 敌可同时进攻的门数随波次上升：骚扰 1 门 → 主力 2 门 → 总攻全门 + 掘墙缺口。

## 3. RTS 核心规则（RTK12 式）

| 项目 | 规则 |
|---|---|
| 时间 | 即时制；速度 暂停 / 1x / 2x；**暂停中可下达全部指令**（暂停 = 免费思考，RTK12 的核心手感） |
| 操控粒度 | 以「队」为单位（一营一队），不操控单兵；我方队数 3~5 支（弓兵营 / 近战营 / 重弩营 / 预备队），敌以「千长队」为编队 |
| 指令集 | 移动 / 驻防（上墙段、堵门、出城列阵）/ 集火指定目标 / **齐射**（技能）/ 撤入城内 |
| 齐射 | 弓兵营爆发技能：短时间高密度射击，之后进入长装填（真空期）。史据：晁错《言兵事疏》「材官驺发，矢道同的，则匈奴之革笥木荐弗能支也」——齐射是汉军克制匈奴皮甲木盾的国家队战术 |
| 战中资源 | **箭矢存量**：箭是经济端物资，战斗中实时消耗，射空弓兵哑火 → 战前经济准备在战中的兑现（本项目的灵魂咬合点） |
| 熟练度 | 沿用 02 已实装的个体熟练度：战力系数 0.6+0.4×prof；溃逃锚 prof 低端；杀敌积累老兵 |
| 俯仰修正 | 城上射城下 ×1.2，城下射城上 ×0.7（占位）。史据：《言兵事疏》「平陵相远，川谷居间，仰高临下，此弓弩之地也」——居高临下是弩的法定地利 |

## 4. 匈奴兵种谱系（8 兵种 + 1 指挥单位）

> 设计原则：每个兵种一条史据 + 一个明确职能 + 一个明确反制。匈奴军攻城器械的史实合理性：匈奴「毋城郭」本不擅攻城，但中行说降匈奴「日夜教单于候利害处」（《史记·匈奴列传》）、卫律为匈奴「穿井筑城治楼」、匈奴历次入塞掳掠工匠人口——**器械营设定为掳掠汉人工匠与降卒建造操作**，质量参差、是敌军中的"异质部队"，既合史又给了设定记忆点。

| 兵种 | 史据 | 职能（分工） | 反制 |
|---|---|---|---|
| 控弦骑射手 | 「士力能毌弓，尽为甲骑」「其长兵则弓矢」（匈奴列传） | 城外游走抛射，压制城头；仰攻受 0.7 修正 | 城上弓兵齐射对射 |
| 射雕者 | 「匈奴射雕者」（史记·李将军列传） | 精锐狙击：点杀城头弓兵/重弩兵 | 数量极少；重弩反点杀 |
| 甲骑突骑 | 「短兵则刀鋋」；白登之围四十万精骑（匈奴列传） | 不能上墙；冲击门洞、**截杀出城近战** → 出城拆器械的天敌 | 被弓兵压制时无法接近；城门口枪阵 |
| 驱虏步兵 | 匈奴驱掠人口为奴「得人以为奴婢」（匈奴列传）；耿恭战中车师仆从军 | 炮灰：填壕、蚁附登城 | 檑木范围杀伤；齐射收割 |
| 冲车 | 《诗·大雅·皇矣》「与尔临冲，以伐崇墉」；《淮南子》注「大铁着其辕端」 | **撞门**：对门血高 DPS；蒙革防箭 | 近战出城拆除；火箭点燃；檑木 |
| 轒輼车 | 《孙子·谋攻》「修橹轒輼」；《墨子·备城门》攻御十二法 | **掘墙**：抵墙持续掉耐久、制造临时缺口；装甲防箭、涂泥抗火一次 | 只能近战出城拆（本方案最硬威胁） |
| 云梯 | 《墨子·备梯》「云梯者，重器也」 | 架梯后步兵蚁附登城，与城头近战 | 推梯（近战在墙上反制）；檑木砸梯下 |
| 井阑 | 战国墨子始载，汉唐常用 | 移动箭楼，与城头同高对射，压制我方弓兵 | **重弩点杀井阑射手**（重弩的专属价值目标） |
| 千长/万骑（指挥单位） | 「大者万骑，小者数千，凡二十四长」（匈奴列传） | 编队核心：提供组织度；被斩首 → 该编队「瓦解云散」溃逃（匈奴列传原文性格） | 重弩/射雕者对位点杀 → RTS 集火决策 |

> 数量控制说明：正式版波次按此谱系组合出场，骚扰波只出前 3 种，器械自主力波起登场。

## 5. 器械克制规则（用户核心思路落地）

**【伤害结构】**（全部占位，待原型验证）：

| 攻击方 → 目标 | 有生力量（步/骑） | 器械（冲车/轒輼/云梯/井阑） |
|---|---|---|
| 普通箭（弓兵） | 基准伤害 | **×0.1 装甲减免**（蒙革铁皮，箭矢刮痧） |
| 重弩 | 高伤（点杀指挥官/井阑射手） | ×0.3（重矢可伤结构，但效率低） |
| 火箭（正式版，耗油） | 基准+灼烧 | **点燃 DoT，器械杀手①**；轒輼涂泥免疫首次点燃 |
| 檑木 | 城下范围杀伤 | **×2，器械杀手②**（站位被压在城下时） |
| 近战出城 | 对步兵均势，对突骑劣势 | **拆除 DPS 基准，器械杀手③（最可靠）** |

**【克制环闭环】**：
- 敌器械不怕箭 → 逼近战出城
- 出城近战被突骑克制 → 出城前须先用弓兵/齐射压制突骑 → **出城是一个"先创造窗口、再执行"的两步决策**，不是无脑操作
- 轒輼涂泥抗火、装甲防箭 → 是"必须出城解决"的压轴威胁；火箭/檑木/重弩各自覆盖一部分器械但都有盲区 → 四种反器械手段无一万能

> 史实注脚：守城方对付蒙革器械，史上确有「近战出城毁械」与火攻两路——《墨子·备城门》通篇即此思路；另《墨子》载**塞门刀车**（门破后以刀车塞门），可给我方近战堵门一个史实升级版，留待定清单。

## 6. 匈奴 AI 战术性格（"不枯燥"的另一半来源）

> 全部出自《史记·匈奴列传》原文性格描写，让敌人"像匈奴"而不只是"血多的小怪"：

| 性格 | 史据原文 | AI 行为落地 |
|---|---|---|
| 诱敌 | 「善为诱兵以冒敌」；白登之围「匿其精兵，见其羸弱」 | 小股骑射手城下游走佯攻，诱玩家出城追击 → 埋伏突骑杀出。**出城追击有真实陷阱** |
| 不羞遁走 | 「利则进，不利则退，不羞遁走」 | 劣势即撤，不硬拼；骚扰波打满掠夺量或损失惨重即退 → 波次式节奏 |
| 逐利 | 「所得卤获因以予之，得人以为奴婢」 | 破门后优先**抢粮抢人**（对应现有破门抢掠规则），不与你死战 → 骚扰波破门≠终局，但总攻破门=败局（继承 02 v2） |
| 瓦解云散 | 「其困败，则瓦解雲散」 | 指挥官阵亡 → 编队组织度清零、溃逃 → 点杀指挥官收益巨大 |
| 多路分进 | 白登之围「西方尽白马，东方尽青駹马，北方尽乌骊马，南方尽騂马」 | 总攻多门由不同"万骑"负责，**各门兵种配比不同**（如正门冲车、侧门云梯+井阑），视觉可用马色区分编队（致敬白登四色） |
| 秋高马肥 | 「秋，马肥，大会蹛林，课校人畜计」 | 正式版钩子：总攻时间锚定秋季 → 与经营线的农时/仓储节奏咬合（联动 01 §5.8 农时议题） |

## 7. 波次结构（多门 + 兵种梯度）

| 波次 | 规模 | 出场兵种 | 进攻面 | 设计意图 |
|---|---|---|---|---|
| 骚扰波 | 小 | 骑射手、突骑、驱虏步兵 | 1 门游走佯攻 | 试探 + 诱出城 + 抢掠即走；拷问战备余量（继承 02 §3） |
| 主力波 | 中 | + 冲车、云梯、井阑 | 2 门（声东击西） | 器械首秀，教玩家"箭打不动器械"；齐射/重弩/出城全决策链登场 |
| 总攻 | 大 | 全谱系 + 轒輼 + 千长队 | 全门 + 掘墙缺口 | 四色分进多门同压；点杀指挥官翻盘；经济+军事总检验 |

## 8. 与切片的关系（落地路径建议）

1. **切片不动**：自动结算版守城战继续验证经济闭环与数值咬合（04 §9 纪律不破）。
2. **RTS 单独立项做轻量原型**：剥离经营层，只做一张城墙地图 + 3 支我方队 + 预设敌波次，验证「暂停下指令 + 出城拆器械 + 点杀指挥官」三个决策点是否成立——原型优先，乐趣验证了再谈整合。
3. 原型验证指标见 §1 验证指标；数值全部沿用「集中配置、一处调参」纪律。
