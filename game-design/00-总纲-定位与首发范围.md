## 1. 品类定位

**一句话定位（三分工）**：

| 钩 | 文案 | 用途 |
|---|---|---|
| A · 机制钩 | 可暂停守城 RTS × 边关屯田经营——你的运输线，就是匈奴的劫掠目标。 | 宣传语 |
| B · 对标钩 | 《Frostpunk》式的经营抉择 × 《三国志12》式的可暂停攻城战。 | **商店首行**、媒体通稿 |
| C · 叙事钩 | 汉匈边塞，屯田守关——养得起兵，才守得住城。 | 开场 CG / 主视觉 |

**Steam 短描述（定稿）**：
> 一款汉匈边塞题材的可暂停守城 RTS + 经营游戏。白天：派工种田、铺运输线、收商税、攒军备。骚扰来袭：收保平民、抉择城门开闭——你的粮道就是匈奴的目标。总攻之夜：指挥步、弓、工兵，齐射、火油、檑木，抓窗口出城拆冲车。匈奴不是血厚的小怪：它们诱敌、伏击、劫粮道，利则进、不利则退。守住城，也要养活人——声望归零，同样败北。

**受众承诺（商店页"关于"末尾，同时是开发纪律）**：
- 适合：喜欢 Frostpunk 的经营张力、TAB/DIO 的守城，但想要"有性格的敌人"的玩家；三国志12 暂停战斗老玩家。
- 不适合：想要 15 分钟一局的摆塔爽游、纯动作割草的玩家。

## 2. 标签策略

| 处置 | 标签 | 理由 |
|---|---|---|
| **主打（前 5）** | City Builder / RTS / Real-Time with Pause / Base Building / Resource Management | 与 DIO、冰汽、TAB 受众重叠，预期对齐 |
| 辅助 | Historical / Singleplayer / 2D / Survival / Economy / War | 正常流量位 |
| 可打但**不进前五** | Tower Defense | DIO 也打了它，但宣传素材从不用"摆塔"话术——**素材里不出现塔防话术比标签本身更重要** |
| 不打 | Roguelite / Card Battler / Action / 塔防作为第一标签 | Super Fantasy Kingdom 简中 57% = 错位代价前车之鉴 |

## 3. 首屏视频 / 截图结构 [PLACEHOLDER · 秒数为初稿]

1. **0–5 秒**：总攻大场面（四色编队多门分进、火油倾倒、冲车撞门）——Steam 首 5 秒决定去留。
2. **5–15 秒**：立刻切「白天种田 → 烽燧报警 → 收保 → 夜里守城」完整循环快剪——15 秒内让玩家知道这是两个游戏合二为一，把「只想纯 RTS」和「只想纯种田」的人提前筛掉。**这步是防差评的核心，不是宣传技巧。**
3. **之后**：史据 AI 记忆点（诱敌伏击片段）+ 账本/声望等经营深度。

### 4.3 砍 · 明确不做（关闭待定项，防 scope 回渗）

- **天气/月相增益**（06 §9.4）——叙事彩蛋可留，机制不做

- **勘探**——首发矿点默认可见（切片裁决维持）

### 4.4 自洽性检验

收敛后的首发单日循环：
> 派工看运输线 → 收商税/接皇帝任务 → 烽燧报警 → 收保+城门决策 → 骚扰波（可自动结算）→ 备战 → 总攻 RTS

清单没有任何一项脱离这个循环，挂档项没有一项是循环的必要条件——自洽。
