## 1. 战斗单位

### 1.1 兵种

| 兵种 | 定位 | 装备消耗 | 特殊能力 |
|---|---|---|---|
| 近战兵 | 地面接战 | 武器（铁匠铺：木+矿） | **可出关野战**（主动出击，拦截/追击） |
| 弓箭兵 | 城楼上射击 | 武器 + 箭矢 | 居高临下，射程优势 |
| 重弩兵 | 操作重弩工事 | 武器 + 重弩（工事） | 远程点杀高价值目标【正式版，随重弩一起解锁】 |

> 重弩 = 工事 + 操作兵种的组合：工事建造后需分配重弩兵操作才生效。

## 1.5 兵员训练体系（军营）

人口分两类：**普通人**（生产岗位）与**兵**（战斗岗位）。转化需经军营：

- 玩家建造**军营**（建筑，耗木）
- 把普通人分配到军营 → 经过**训练周期 T**（时长待原型验证）→ 成为合格兵
- **训练期占用人口**：受训者不事生产，但仍耗粮 → 国防开支与生产投入直接竞争

### 提前征召（核心张力）

训练未完成就被拉上战场时，获得两项 debuff：

| 属性 | 效果 | 对远程兵（弓箭/重弩） | 对近战兵 |
|---|---|---|---|
| **战斗熟练度低** | 部队强度打折 | 命中率↓、伤害值↓ | 伤害值↓、防御值↓ |
| **士气低** | 战斗意志不稳 | 共通：**容易出现逃兵**（单位脱战逃跑，待数值验证） | 共通：同上 |

设计意图：
- 骚扰波次不再只是"战斗事件"，而是**对玩家战备节奏的拷问**——常备军养多少？应急拉壮丁的代价能不能接受？
- 熟练度让"兵"有了质量维度，防止爆兵流一刀切
- 逃兵机制让提前征召有真实痛感，但不至于一败涂地（损失部分兵力而非全灭）

### 军队后勤：粮与饷（已确认加入）

- **兵吃粮比普通人多**（倍数待原型验证）→ 养兵 = 双倍粮食压力
- **兵要军饷**（钱，按周期发放，金额待原型验证）→ 养兵 = 持续金钱出血
- **军队粮饷补给不够 → 兵变**：兵变成批转为逃兵（区别于个体士气逃兵，兵变是系统性崩盘）
- 普通人粮食耗尽 → 人口减少（联动 03 文档饥荒规则）

设计意图：军饷让"钱"有了最刚性的出口——玩家可以少建建筑，但不敢欠饷，因为兵变 = 防线瞬间蒸发。史实依据：明九边缺饷兵变（宁远兵变、蓟州兵变）。

#### 史据锚点（2026-09-29 查证，数值设计参考）

- **汉代居延汉简《廪食簿》**：戍卒月廪粟 3石3斗3升 ≈ 平民家属（成年女性 2石9升）的 **1.6 倍**；且「廪食（粮）+奉钱（饷）」双轨发放，隧长月俸钱六百至九百。→ 「兵吃得多 + 粮饷双轨」结构出自国家台账定制。
- **明代九边「双粮」**：万历二十二年辽东定例，家丁「每月食双粮，即银八钱」，额军四钱——「双粮」为官方文书原词，精锐待遇 ×2。
- **明代墩军岗位津贴梯度**（弘治十年大同）：守大边行粮一石、二边五斗、腹里三斗——**距敌越近吃粮越多**，在月粮之外叠加。→ 正式版「上墙守军吃行粮」机制的史据。
- **切片简化声明**：史实军饷按月发放、欠饷按月爆发；切片改日结（单局 20~30min 的压力颗粒度需要）。**正式版候选**：按月发饷 + 欠饷缓冲期（积欠 N 日才触发逃兵判定），天然形成「月底钱荒」节奏。
- 数值对照：切片兵粮 ×2（民 1）落在史实区间（×1.6~×2）上限，可解读为「守关常备 = 常年在岗行粮」；模块 17 调参时若觉得压力过大，可先降到 ×1.5（贴汉代），再动别的。

### 熟练度与士气的恢复（规则草案）

- 熟练度：训练期满即满值；战斗中存活也可缓慢积累（老兵机制，正式版深化）
- 士气：随时间自然恢复；胜仗/粮草充足加成恢复（待设计）
- 切片实现：**熟练度两档制**（未训完=低 / 训完=满），士气单值简化，逃兵用简单概率公式

#### 重构提案（2026-09-29 用户提出，**当日裁决「做」并已实装**）

**问题确认**：士气为全营单值 → 新兵白捡老兵状态（士气 100 时入伍=满状态起跑）、欠饷打击被新兵洗白——混编部队无区分度，结构性缺陷。

**已实装内容（slice/index.html，回归全绿）**：
1. **士气维度退役**（切片内）：入营即 100% 不再跟踪。旧士气挂钩项全部改道——
   - 提前征召 debuff → 连续熟练度天然接管（少训=少熟练，账更清楚）
   - 欠饷逃兵 → 直接挂欠饷天数（desertBase 10% 起，每多欠 1 日 +5%）
   - 战场溃逃判定 → 锚熟练度（新兵易溃、老兵稳，史实一致；模块11 接）
2. **熟练度个体化 + 连续值**：平民 0%；受训每日 +16%（trainProfPerDay）；出营熟练度 = X×已训天数（提前征召同公式）；**满训出营 80% 不满值**，剩余 20% 靠杀敌积累（每场按歼敌比重 +，模块 11 定）。战力系数 = 0.6+0.4×熟练度（训 1 天 0.66 ≈ 旧仓促 0.6；满训 0.92 ≈ 旧满练 1.0，数值平滑衔接）。
3. 实现落点：个体熟练度存 `state.troops[]`（每兵一条 {prof}），`soldiers` 为派生计数（setRes 双向同步：增兵 push、减兵自动移除熟练度最低者=新兵先跑）；受训中无需跟踪（queue 剩余天数即熟练度来源，出营一次算清）。军营面板显示「部队：N 人 · 平均熟练 X% · 未满训 N · 老兵 N」。
4. 退役字段：morale / rushSoldiers / rushPower / trainedPower / unpaidMoraleHit / desertRate（morale 与 rushSoldiers 保留占位恒定值，防旧引用报错，正式版清理）。

**留给模块 11 的接口**：战力 = 0.6+0.4×prof；杀敌成长 +prof（上限 100）；战场溃逃判定锚 prof 低端；战死移除可指定个体（先 splice 再减计数）。

## 3. 战斗节奏结构（与核心循环咬合）

| 阶段 | 战斗内容 | 对经济的影响 |
|---|---|---|
| 平时 | 无战斗 | 全力种田 |
| 小股骚扰 | 零星匈奴小队袭扰 | **打断种田节奏**：逼玩家提前留战备余量，不能 100% 资源投发展 |
| 攻城大限 | 匈奴主力总攻 | 全资源转化为战力的最终检验 |

## 4. 与塔防形态的关系

- 长城 = **线式防御**：敌人沿关隘正面多段进攻，玩家决定兵力/工事投放在哪段墙
- 近战兵出关野战 = 塔防之外的"主动出击层"，风险换收益（待设计：出关的回报是什么？歼灭骚扰队？夺取物资？）
