## 1. 兵种总表（v0.2 定名）

### 1.1 我方兵种（兵营培育三种）

| 兵种 | 定位 | 说明 |
|---|---|---|
| 步兵 | 近战 | 堵门承伤、**出城拆敌攻城器械**（核心反器械手段） |
| 弓兵 | 远程 | 城上射击（俯射加成），对器械伤害大幅减免（刮痧） |
| 工兵 | 工程 | 操作**檑木、火油、重弩**三样防御器械（无人操作=死物） |

> 剑与箭设定已取消：武器不计入、非消耗品，步兵/弓兵零装备门槛（v0.2 用户简化）。
> 「士」为预留概念，当前战斗人员统称「兵」。

### 1.2 匈奴兵种（七单位，玩家易记两字名）

| 兵种 | 职能 | 反制 |
|---|---|---|
| 游骑 | 骑兵·远程骚扰：城外游走抛射、毁田、杀平民、劫粮道、烧烽燧 | 城上弓兵对射；出兵驱逐 |
| 弩骑 | 骑兵·精锐远程：点杀城头弓兵/工兵 | 重弩反点杀；数量稀少 |
| 铁骑 | 骑兵·近战：**截杀我方出城步兵**；骚扰期**城门开启时入城**杀人、掠粮、抢钱，抢完即走不占城 | 出城前先用弓兵压制；及时收保+关闭城门 |
| 步兵 | 自带云梯登城，蚁附爬墙 | 檑木范围杀伤、齐射收割 |
| 冲车 | 器械·撞门：对门血高伤害，蒙革防箭 | 步兵出城拆除、火油、檑木 |
| 井阑 | 器械·移动箭楼：与城头同高对射，压制我方弓兵 | 重弩点杀井阑射手 |
| 云梯 | 器械·由匈奴步兵携带架设（非独立单位） | 砸毁梯下聚集敌兵 |

> 命名原则：两字、望文生义。史实名（控弦、射雕者、轒輼等）留作图鉴考据彩蛋。
> 器械营设定：由掳掠汉人工匠与降卒建造操作（史据：中行说、卫律降匈奴；匈奴历次入塞掳掠工匠）。

## 2. 兵营与熟练度（v0.2 定案）

### 2.1 兵营结构

- 建一座兵营 = **步兵营 + 弓兵营 + 工兵营** 三营同时建成
- 玩家指派**平民**入营受训；受训期不事生产，但仍耗粮（国防与生产抢人）
- 兵营详细设计后续专项讨论

### 2.2 熟练度规则

- **满训出营 = 80% 熟练度**；剩余 20% 靠搏杀积累
- **提前出营**：按已训天数折算（公式同下表）
- 战力系数 = **0.6 + 0.4 × 熟练度**（切片已实装公式沿用）

| 受训天数 | 出营熟练度 | 战力系数 | 定位 |
|---|---|---|---|
| 0（拉壮丁） | 0% | 0.60 | 炮灰，极易溃逃 |
| 1 | 16% | 0.66 | 提前出营 |
| 2 | 32% | 0.73 | |
| 3 | 48% | 0.79 | 半成品 |
| 4 | 64% | 0.86 | |
| **5（满训）** | **80%** | **0.92** | 合格兵 |
| 战后老兵 | 80→100% | 0.92→1.00 | 老兵 |

- 战斗成长（占位）：**存活一场 +3%，每亲手击杀 1 敌 +0.5%**，上限 100%（满训兵约 5~7 场满级）
- 满训周期 T = 5 天、每日 +16%（占位，待原型验证）
- 战场溃逃判定锚定熟练度低端（新兵易溃、老兵稳，切片已实装）

### 2.3 军队后勤：粮与饷（沿用，史据已查证）

- 兵耗粮多于平民（切片 ×2，史实区间 ×1.6~×2：居延汉简戍卒月廪 ≈ 平民 1.6 倍；明九边家丁"双粮"×2）
- 兵发军饷（钱）；**欠粮欠饷 → 兵变逃兵**（成批脱逃，系统性崩盘）
- 正式版候选：按月发饷 + 欠饷缓冲期（积欠 N 日才触发），形成"月底钱荒"节奏
- 史据锚点：居延汉简《廪食簿》廪食+奉钱双轨；明代墩军行粮梯度（距敌越近吃粮越多）

## 3. 城防体系（v0.2 更新）

### 3.1 城防材质：土

- **城门/城墙防御值由筑城土质决定**；土产自矿洞
- 材质等级由**科技树**决定，越好城防越高：**夯土 → 三合土 → 砖包城**（史据：先秦版筑夯土《诗经》"缩版以载"；汉边塞皆夯土城；明清砖石包砌）
- 城门 = 特殊墙段：耐久低于墙、可被撞开、通行口；**多门为关卡配置（2~4 门 + 天险面）**（史据：疏勒城北西面筑墙、东南以深涧为屏障）
- 门耐久累积不自动恢复；修门耗**土+木**（土多木少，占位：土 20 / 木 5 修满一扇；筑城材质升级耗土+钱——造价全表见 01 §4.3）

### 3.2 防御器械（工匠坊产出，工兵操作）

| 器械 | 材料 | 定位 |
|---|---|---|
| 檑木 | 木+铁 | 城下范围杀伤（对聚集敌兵与器械 ×2） |
| 火油 | 工匠坊直接产出 | **城头倾倒**，对器械点燃持续伤害（器械杀手。火箭设定已取消，统一为火油一种） |
| 重弩 | 木+铁 | 远程点杀高价值目标（弩骑、井阑射手） |

### 3.3 器械克制环（核心手感）

| 攻击方 → 目标 | 有生力量 | 攻城器械 |
|---|---|---|
| 弓兵（箭） | 基准伤害 | **×0.1 装甲减免**（蒙革防箭，刮痧） |
| 重弩 | 高伤点杀 | ×0.3 |
| 火油 | 基准+灼烧 | **点燃 DoT** |
| 檑木 | 城下范围 | **×2** |
| 步兵（出城） | 对步兵均势、被铁骑克制 | **拆除，最可靠** |

> 克制闭环：器械不怕箭 → 逼步兵出城；出城被铁骑克制 → 先用弓兵压制铁骑再抓窗口出城——**出城是"先压制、再执行"的两步决策**。

## 4. 波次结构（v0.3 定案）

| 阶段 | 内容 |
|---|---|
| 平时 | 无战斗，全力经营 |
| **骚扰波**（多波） | **不攻城**（不撞门、不拆墙）。城外：游骑毁田、杀城外平民（农民/矿工/背货工人/勘探者/夜宿驿站的商人——背货者被杀**货随人劫走**）、劫粮道（抢产地存量）、烧烽燧。**城门开启** → 小股铁骑入城杀人、掠粮、抢钱（单次上限占位：**粮 = 城内库存 10%、钱 = 15%**，**抢完即走不占城**）；**城门关闭** → 不进城，只在城外活动。玩家不出兵就硬吃损失（人口/资源/声望下降） |
| **总攻**（最终波） | **攻城**。AI 随机决定：**多门齐攻 或 猛攻一门**；器械齐上（冲车/井阑/云梯步兵） |

> 骚扰期的门：白天门默认开启（背货工人、商人进货、农民上工都要走门）。骚扰来袭时——**紧急关门 = 把城外自己人锁死** vs **保持开门 = 赌铁骑不入城**。预警（烽燧/探马）的价值 = 留出"收保 + 关门"的决策窗口。

### 4.1 铁骑入城·城内拦截结算（2026-10-05 定案，一条公式不占巷战层）

背景：不做巷战已定案，但开门期间玩家纯看戏吃 10%/15% 损失是 RNG 不是决策（外部评审 P2）。解法：**城内驻留近战队对入城铁骑做一次简化拦截结算**——玩家「留不留兵在城里」变成真决策，不再需要实时操作。

**公式（全部 [PLACEHOLDER · 待原型验证]）**：

```
拦截击杀数 K = min( ⌊城内近战兵力 × 拦截系数 I⌋ , 入城铁骑数 R )
被抢比例  = 原比例 × (1 − K / max(R, 1))
我方损失  = ⌊K × 交换损耗 0.4⌋ 名近战（阵亡，永久减人口）
```

| 参数 | 占位 | rationale |
|---|---|---|
| 拦截系数 I | 0.5 | 预备队以逸待劳、主场巷道 familiarity；对纯骑劫掠者（不恋战）能吃掉一半 |
| 交换损耗 | 0.4 | 拦截是有利战斗但非零成本——低于野战 1:1，守住「出城打野战仍是最差选择」的格局 |

**玩家决策空间**：入城抢掠上限 10%/15% 是天花板——拦截只能**减损**，不能变成刷兵收益（K>R 时不多杀）；把近战留在城内 = 放弃出城追击游骑的主动权。兵符上墙的近战**不参与**拦截（在墙不在城）。
**实现落点**：切片 `raidRounds` 结算处加两行；实装时同步声望账本（「拦截杀伤」条目，让收益可见）。

### 胜负判定（v0.3 定案：硬条件 + 每关附加条件占位）

| 结果 | 条件 |
|---|---|
| 败 | **声望归零**——即时判败，任何时候触发（联动 03 文档） |
| 败 | **总攻中匈奴涌入城内**——**门破 ≠ 败**：门破后匈奴未涌入不算输，可用步兵堵门洞做最后窗口；**不做独立巷战层**（原待定问题 5 关闭） |
| 胜 | 守过总攻 且 声望未归零 |
| 占位 | 每关可设附加失败/胜利条件（随关卡难度梯度），正式开发时逐关讨论 |

## 5. 预警体系（v0.2 新增）

| 层级 | 解锁 | 性质 | 能力 |
|---|---|---|---|
| 烽燧 | 默认可建（城外，耗土+木，造价见 01 §4.3） | 被动视野 | 驱散周围迷雾；敌入视野提前报警（显示规模与方向）；**被游骑优先烧毁**，毁后迷雾合拢需重建 |
| 探马 | 科技树解锁 | 科技强化 | 迷雾驱散范围更广、预警时间更早（**提前约半个月**知敌动向） |

- 烽燧史据：汉代边塞"五里一燧，十里一墩"；居延汉简《塞上烽火品约》按敌规模分级信号（昼烟夜火）
- 探马史据：汉军候骑/斥候；《史记》匈奴"候骑至雍甘泉"
- 预警 = 「收保」决策窗口：报警后玩家可把城外平民撤回城内（史据：边塞遇警"入保"）

## 6. 匈奴 AI 战术性格（沿用，出自《史记·匈奴列传》）

| 性格 | AI 行为 |
|---|---|
| 诱敌（"善为诱兵以冒敌"；白登"匿其精兵，见其羸弱"） | 小股游骑佯攻诱玩家出兵追击 → 铁骑伏击 |
| 不羞遁走（"利则进，不利则退"） | 劣势即撤，波次式节奏 |
| 逐利（"所得卤获因以予之"） | 骚扰以抢掠杀掳为目标，不硬拼 |
| 多路分进（白登四色马队） | 总攻各门兵种配比可不同；视觉可用马色区分编队 |
| 秋高马肥（"秋，马肥，大会蹛林"） | 正式版钩子：总攻锚定秋季，联动农时 |
