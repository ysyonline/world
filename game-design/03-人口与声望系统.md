## 1. 核心规则

- **战死 = 人口永久损失** → 必须有人口补充机制对冲，否则游戏随时间必死
- 人口来源三条：**初始人口**、**自然增长**（声望驱动）、**俘虏转化**
- 人口出口三条：**战死**、**自然死亡**、（饥荒饿死——规则待定）

### 3.4 声望中枢化（v0.2 定案）

**定位**：声望 = **民间与边地对你的口碑**；政治点 = 朝廷对你的评价（07 文档）。朝廷看报表，百姓看日子——两套评价分立。

**涨跌因素**：

| 声望涨 | 声望跌 |
|---|---|
| 打退匈奴（按波次规模） | 被骚扰波得手（毁田/杀平民/劫粮道） |
| 连续无饥荒（安居乐业天数） | 饿死人、饥荒持续 |
| 商业繁荣（在营商人数量） | 杀俘 |
| 收留流民事件 | 欠饷兵变、逃兵 |
| | 皇帝任务失败（朝廷申饬丢面子） |

**人口规模 = 放大器（非来源）**：同样的事件，人越多传播越快——胜仗在小关 +5、大关 +15（示意）；饿一人在小关无人问、大关流言四起。防"人口→声望→更多人口"滚雪球失控。

**声望收益（五项）**：

1. **流民来投加速**——人口流入阀门总开关（沿用 §3.1）
2. **商税与互市规模加成**——名声好，商旅敢来、敢走你的道 → 直接生钱
3. **义勇与老兵投奔**——概率事件：退伍老兵/逃散工匠慕名来投，自带熟练度（兵与工的高质量来源）
4. **朝廷拨付/任务奖励加成**——名声传入朝廷，拨付更痛快（与政治点互补）
5. **双刃剑**：声望越高、关越富，**匈奴主力波规模越大**——"塞上肥关，胡骑必至"，声望系统自带平衡 |

### 3.1 人口自然更替

- **出生**：声望达标后，按人口基数比例，每 x 天 +1 人（x 与比例待原型验证）
- **自然死亡**：按人口基数比例，每 y 天 −1 人（y 与比例待原型验证）
- 设计意图：人口是"活水"，声望决定水位高低——玩家长期的道德与经营质量直接兑换成劳动力规模

### 3.2 饥荒机制（已确认）

- **触发**：粮食低于**动态阈值**即进入饥荒，**不用等粮尽**；阈值与当前人口成比例（比例系数待原型验证）
- **饥荒期间**：持续减少声望
- **粮食耗尽**：普通人口减少
- **军队缺粮/欠饷**：兵变（见 02 文档军队后勤）

设计意图：动态阈值让饥荒成为"提前预警的慢性病"而非"突然暴毙"——玩家有窗口期救灾（开仓？进口？减少人口消耗？），但声望的持续流失逼着玩家不能躺平挨饿。

### 3.3 胜负判定（已确认）

| 结果 | 条件 |
|---|---|
| **败** | ① 长城被攻破（城破） |
| **败** | ② 声望低于**本关隘声望底线 x**（底线由系统按关隘设定，每关不同——联动失败条件与关卡难度） |
| **胜** | 守过攻城大限 且 声望在底线以上 |

设计意图：双失败条件 = "军事不能输，治理也不能烂"。玩家可能守住了城但民生凋敝声望崩盘，照样判败——这正是"屯田戍边"的历史内核：守边从来不只是打仗。

## 4. 俘虏机制（骚扰/攻城战的战后环节）

每次匈奴来袭结束后，敌方损失分为**战死**与**俘虏**。玩家对俘虏二选一：

| 处置 | 即时效果 | 长期效果 | 风险 |
|---|---|---|---|
| **杀死** | 省粮省事 | **声望 ↓** → 人口流入减少 | 无直接风险 |
| **关押** | 占用管理（是否耗粮/需牢房建筑，待定） | 一定概率**转化为己方人口**；保声望 | 一定概率**逃跑**（转化率/逃跑率待原型验证） |

设计意图：
- 战后抉择 = 短期利益（省粮）vs 长期利益（人口+声望），与种田/战备的资源取舍同构
- 俘虏是骚扰战的"掉落物"，让挨打也有收益可能，降低骚扰的纯负面感
