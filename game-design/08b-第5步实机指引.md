# 第 5 步 · C 信号实机验收指引（C 是生死线，必须你亲自跑）

> 2026-10-06 立。本文档只服务一件事：**让你 30 分钟内给「支柱 3 · 后果可归因」拍一次板**。
> A 信号已自动化（settle-smoke 41→51 断言全绿）、B 信号已出实测区间（见 pacing.js 输出），
> 只有 C 信号的**主观面**机器判不了——它问的是「你输了以后知不知道该怪哪个决策」。

## 0. 先说结论：现在这关你**应该会输**

pacing.js 实测：v0.3 数值下，最小获胜经济策略在第 40 天只能养出 **4~7 个兵**，
而总攻是 **36 个单位的四色编队**。回合制下 4 兵守得住（1:3 兑子 + 器械压制），
实时战斗下 4~7 兵被碾平。

**这不是 bug，是两个子系统对「一支守军该有多少人」的假设没对齐**，
而第 4 步的测试用「手工构造的 33 兵」做守恒验证，正好跳过了「策略真能养几个兵」这个真问题。

所以下面第 1 步故意让你**输**——因为 C 信号只在失败时才可判。
如果你赢了，反而说明这关没难度、C 信号无从验收。

## 1. 实机流程（约 30~40 分钟）

### 准备
双击 `slice/index.html`（用 Chrome/Edge）。开 F12 控制台留着。

### 开打
按下面这套「最小获胜策略」操作——**和 pacing.js 跑的是同一套**，这样你看到的和工具测的是同一个东西：

| 日 | 操作 |
|---|---|
| 开局 | 外郊 2 座农田 + 1 座伐木场，全部满员（农田各 5 人、伐木 3 人） |
| D4 | 建矿洞，满员 3 人 |
| D4 起 | 建市坊（自动抽闲民当商人） |
| 人口快满上限时 | 建民房（5 人/座） |
| 钱 ≥ 90 且已有市坊 | 建兵营 |
| D14 | 第 3 座农田（满员） |
| D22 | 第 4 座农田（满员） |
| D11 起 | 兵营排队送训：步 弓 步 弓 工 步 弓 工 步 弓 步 步 |
| 每天 | 补岗（农田→伐木→矿，闲民优先塞满）；弓兵自动分 4 段上墙；仓库有檑木/火油/重弩就往上墙段部署；门破了就修 |
| 骚扰前 1 日 | 点「收保」；骚扰过去后点「复工」 |
| D40 | **总攻日：自动进实时战场。** 弓兵上北墙、步兵上门侧墙、工兵贴前门、步兵居中救火；敌人上墙就放檑木/火油，门破就抢修 |

### 记下三件事（这才是验收数据，不是玩得爽不爽）
1. **总攻日你带了多少兵**？（看顶部 HUD 的「兵」）
2. **整局大概花了多久**？分开记：经营期约多少分钟（指你在动脑子的时间，不是一直挂着的墙钟时间）、总攻战多少分钟
3. **败了以后，你看结算面板那几行字，能说出「下局该改什么」吗？**

## 2. 判定标准（C 信号的三档）

看结算面板的归因链（终局大面板里逐条列出的【门】【兵】【械】【练】【毁】+ 总评句）：

**C 通过** —— 你能指着面板上某一条，说出「我错在这儿，原因是上一局做了 X」，
并且 X 确实是**经营期的一个决策**（不是「我手速不够」「我菜」这种）。
例：「【兵】殉国 6 人，战前在编 7 人、平均熟练度 62%」→ 你想到「我该早送训 / 该拉长训练周期」= 通过。

**C 半过** —— 你知道大概该加强兵，但面板没给出**具体是哪一步**。
例：你说「我兵太少了」，但面板没让你看清「40 天只送出 8 次训」。
→ 这说明归因链挂错了决策点，需要改的是**归因本身**而不是数值。

**C 不通过** —— 你输得莫名其妙，只能靠重开试。
例：面板说「门破而城未陷，靠的是堵门洞的血肉」，但你觉得「我根本没得选啊」，
或者面板说的原因和你实际的失败过程对不上。
→ **C 是生死线**：立不住就意味着「同图双模式」不成立，得回退重议分场景方案。

## 3. 顺带请你拍另一个板：经济产出 vs 战斗烈度断层

pacing.js 给了三个修法方向，**这属于设计决策不是调参**，需要你选：

**① 修经济（治本）**：训练/产出提速，让 40 天能养出 20+ 兵。
代价：会动摇 v0.3 定的经济平衡（钱/粮/木全要重算），且经营期会从「慢思考」变成「忙不过来」——
而经营期变忙正好会把 B 信号的 65:35 推向「战斗太少」，一步两个问题。

**② 修战斗（治标，但最符合设计本意）**：按实际守军规模缩放敌编队。
好处：总攻强度随玩家成长而缩放，这本来就是 03 §3.4「声望双刃剑联动下次总攻规模」想要的——
现在总攻规模写死在 battle.js 的 spawnSiege 里（36 单位、无 RNG），等于这条联动根本没接上。
代价：可能出现「我很强但打得和弱时一样」的观感问题。

**③ 拉长准备期**：总攻日从 D40 后延（比如 D55），让兵练出来。
代价：关卡变长，B 信号进一步偏向经营（战斗占比下降）。

**我的建议是 ②**，理由是它同时修掉一个更根本的问题（总攻规模与玩家成长脱钩），
而且不动 v0.3 经济平衡——① 和 ③ 都是在没有先验证战斗侧的前提下改经济，风险更大。
