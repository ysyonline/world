# 经济模型 · 物资骨架 v0.2

> 状态：孵化草案 | 数值全部「待原型验证」
> 项目：古风种田+策略+塔防（长城关隘）| PC · 单机 · 单人开发
> 时代定位：**架空**（保留"匈奴"称谓与攻城设定）
> **v0.2 修订（2026-10-03）**：吸收用户讨论定案——人口职业化（农/工/商/脚夫/兵）、生产建筑全部移到城外、运输线模型（脚夫+粮仓入库）、勘探机制、商肆建筑、宵禁制度、钱来源定为「皇帝任务+商税」。旧切片范围裁定保留待整体重议（见文末）。

## 1. 设计总纲：一人口三约束

- **人口** 是隐藏核心资源（总闸门）：每人每日耗粮；人口填充各职业
- **三约束**：粮养人（饿不起）→ 人上岗（岗位有限）→ 岗驱动产线（多条产线抢人）
- **物资入库规则（v0.2 新增）**：产出物**运抵城内粮仓/库房才算入库可用**——运输是独立环节，由脚夫承担（见 §5）

## 2. 人口与职业（v0.2 重构）

```
人口
├── 闲民（未配属，一切职业的来源池）
├── 农（农民）→ 城外农田
├── 工（矿工/樵夫/工匠统称）→ 城外矿洞、伐木场；城内工匠坊、酒坊、茶坊、布坊
├── 商（酒商/茶商/粮商/布商）→ 对应四类商铺
├── 脚夫（差事）→ 运输线：城外产出 → 城内粮仓/库房
└── 兵（弓兵/步兵/工兵）→ 由平民入兵营受训转化（详见 02 文档）
```

- 平民可在 **农/工/商/脚夫** 间由玩家调配；受训为兵则脱离平民池
- 「士」为预留概念，后续版本补全，当前不设
- 战死、被杀（骚扰）、饿死 = 人口永久损失；补充靠声望驱动流入与俘虏转化（详见 03 文档）

## 4. 建筑总表（v0.2 按位置重排）

### 4.1 城外建筑（可被匈奴袭扰破坏）

| 建筑 | 说明 |
|---|---|
| 农田（粟田/桑田） | 配农民；产出需经脚夫运入城才入库（见 §5） |
| 矿洞 | **需先派平民「勘探」发现矿点才可开采**；产土+铁 |
| 伐木场 | 玩家建造；产木 |
| 烽燧 | 无需驻守；驱散迷雾、敌袭预警；会被游骑优先烧毁（详见 02 文档） |

### 4.2 城内建筑

| 建筑 | 说明 |
|---|---|
| 粮仓/库房 | 入库终点；运输线的目的地 |
| 兵营 | 一营建三营：步兵营/弓兵营/工兵营同时建成（详见 02 文档） |
| 工匠坊 | 产檑木、火油、重弩（原铁匠铺改名简化） |
| 酒坊/茶坊/布坊 | 商类建筑·初级，玩家建造；**科技树解锁后升级为酒肆/茶肆/布肆**（"肆"为汉代市肆制原词：《汉书·食货志》"开市肆以通之"） |
| 望火楼 | 科技树解锁；消除夜开城门的偷盗/失火事件概率（见 §7） |

## 5. 运输线系统（v0.2 核心新增）

```
农田（配农民）→ 熟成 X 天产出 → 田间存量
  → 脚夫搬运 → 城内粮仓 → 才算入库可用
```

| 规则 | 内容 |
|---|---|
| 脚夫来源 | 从**闲民**中挑选配属 |
| 默认行为 | 玩家不配脚夫 → 自动从所属农田**抽农民自运**（占务农人力，隐性惩罚） |
| 新手教程 | 玩家建造第一块田时触发，教玩家配置脚夫、建立运输线 |
| 劫粮道 | **匈奴骚扰必劫运输线**（史据：白登之围"中外不得相救饷"）→ 护粮道是骚扰期核心决策 |
| 切片实现 | 简化：只体现"有运输"的概念（如每日运力结算） |
| 正式版实现 | **必须实现可见的运输效果**（用户明确要求：脚夫小队在田与城之间走动） |

## 6. 勘探机制（v0.2 新增）

- 矿点不可见，需玩家**派平民出城勘探**；勘探发现矿点后才可建矿洞开采
- 勘探期平民在城外暴露，有被游骑袭击的风险
- 具体耗时/成功率：待原型验证

## 7. 宵禁与商人作息（v0.2 新增）

商人一日时间轴：

```
白天  城内做生意（生钱/商税）
下午  出城进货
傍晚  回城——回城时间随机，可能在宵禁前，也可能在宵禁后
夜间  城门宵禁，默认关闭（绝对安全，无任何事件）
```

| 规则 | 内容 |
|---|---|
| 手动放行 | 宵禁后商人回城，需玩家**手动开门放行** |
| 自动开门 | 嫌烦可设置城门夜不关闭 → 夜间概率事件：**偷盗**（损失钱+粮）、**失火**（烧毁建筑）；事件只在开门状态触发，关门绝对安全 |
| 望火楼 | 科技树解锁建筑；装备后开门事件概率归零 |
| 滞留后果 | 不放行 + 匈奴来袭 → 城外商人被屠杀（损失玩家自己的人口资源） |

## 8. 岗位效率曲线（沿用，核心机制）

设建筑岗位上限为 N，在岗人数为 x：

- `x ≤ N`：效率 = (x / N) × 100%
- `x > N`：效率 = max(0, 100% − k × (x − N) / N × 100%)，k ≈ 2~3 待调

设计意图：缺员有代价、超员有惩罚、每条产线都缺人 → 资源分配张力贯穿全局。

> 候选简化（用户曾提出，待裁决）：改「Y/人 + 满员奖 X」公式，心算更友好。候选数值：农田 Y2/X2、伐木 Y2/X0、矿洞 Y1/X2、工匠坊 Y1/X0（满岗总量 12/8/6/3）。

## 9. 与关隘系统的联动钩子（沿用）

- 矿点位置固定且依地形分布 → 矿是否好采成为关卡变量
- 关隘地势/天气/地貌影响产线效率（寒冷关隘粮产下降等）
- 田块数量/质量随关隘变化
