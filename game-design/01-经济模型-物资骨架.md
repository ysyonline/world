## 1. 设计总纲：一人口三约束

- **人口** 是隐藏核心资源（总闸门）：每人每日耗粮；人口填充各职业
- **四约束（v0.4）**：粮养人（饿不起）→ **房住人（住房定上限，见 §2.1）** → 人上岗（岗位有限）→ 岗驱动产线（多条产线抢人）
- **物资入库规则（v0.4 修订）**：产出物**运抵城内粮仓/货仓才算入库可用**——运输是独立环节，v0.4 起由**产者自运**承担（脚夫职业废除，见 §5）

## 2. 人口与职业（v0.2 重构）

```
人口
├── 闲民（未配属，一切职业的来源池）
├── 农（农民）→ 城外农田
├── 工（矿工/樵夫/工匠统称）→ 城外矿洞、伐木场；城内工匠坊、酒坊、茶坊、布坊
├── 商（酒商/茶商/粮商/布商）→ 对应四类商铺
└── 兵（弓兵/步兵/工兵）→ 由平民入兵营受训转化（详见 02 文档）
```

- 平民可在 **农/工/商** 间由玩家调配；受训为兵则脱离平民池（v0.4：脚夫职业废除，运输由产者自运，见 §5）
- 「士」为预留概念，后续版本补全，当前不设
- 战死、被杀（骚扰）、饿死 = 人口永久损失；补充靠声望驱动流入与俘虏转化（详见 03 文档）

### 2.1 住房（民房）与人口上限（v0.4 新增）

- **民房**：城内建筑，每座容纳 **5 名平民**（切片占位，正式版重调）；造价 钱20+木10（见 §4.3）
- **开局**：送 **6 座民房** = 人口上限 30 = 初始人口 30（**满员开局**，第一天就埋下"住房是刚需"的认知）
- **软上限**：人口**可以超过**住房上限（流民照常来投、不拦截），但超出部分为**闲民**——照常耗粮、**无法派工**，直到新建民房
- **士兵不占民房**（住营房；切片内兵营不另设容量上限）
- **面板口径**：`民 32/30`——总数/上限白字、在岗绿字、闲民红字；**不区分"无业"标签**（闲民 = 吃粮不干活，玩家自会利用）
- 设计意图：住房把"流民来投"从纯福利变成**需要投资才能兑现的福利**——声望高人来得多，接不住就是纯耗粮负担，与"种田养军 vs 穷兵黩武"同构

## 5. 运输线系统（v0.4 重写：产者自运）

```
农田（配农民）→ 产出实时累积于产地存量（未入库 ≠ 玩家可用）
  → 存量攒够 5 担 → 自动派 1 名在岗工人背回城 → 入库，才可用
```

| 规则 | 内容 |
|---|---|
| 结算粒度（v0.4） | 产出**秒级实时**累积于产地；入库事件即玩家收入（日结只管耗粮/军饷/商税/波次等） |
| 自运调度 | 产地存量 ≥ **5 担** → 自动派 1 名在岗工人背回对应仓库 → 返回继续干活；**走路期间不产出**（误工看得见，替代旧"次日效率×0.6"隐性惩罚） |
| 负重与速度 | **5 担/人/趟**、步速 **60 像素/秒**（切片占位，进 CONFIG 可调）→ 实测"运输税"约 **13%~19%**（按 1 日=30 秒、单人日产 粮4/木4/矿2 单位测算：农田≈13%、伐木≈19%、矿洞≈13%） |
| 距离即纵深 | 越远运输税越重 → 矿洞选址、仓库选址成为真实决策（脚夫池给不了的纵深） |
| ~~脚夫~~ | **v0.4 废除**：脚夫职业、12 单位/人/日、农民自运×0.6 惩罚整套删除——运输成本从"抽人"变为"占工时" |
| ~~存量折损~~ | **v0.4 删除** 1%/日折损：自运时代存量瞬态、几乎不触发；运输紧迫感由"暴露即风险"（存量可被劫、人可被杀）物理承载。正式版若做远程屯粮/商队可局部回归 |
| 双仓制 | **粮仓**（粮）+ **货仓**（木/土/铁），城内；开局各送 1 座、切片各限 1 座；夜赌·失火豁免两仓 |
| 收保联动 | 收保 = 工人停工**走路回城**、到达变闲民；背货途中收保 → 先入库再回城；产地存量留原地（无折损、可被劫） |
| 战时损耗 | 背货者被骚扰波杀死 → 背上物资**随人被劫走**（战报提及） |
| 劫粮道 | **匈奴骚扰必劫运输线**（史据：白登之围"中外不得相救饷"）→ 杀背货工人、抢产地存量；收保保人是核心对策 |
| 运输线面板 | **一条线 = 一个产地建筑 → 对应仓库**；列表显示：线路名 + 在运物资 + 今日累计入库 + 状态（运输中 / 待运 N 担 / 收保停产 / 无人上岗）；点行高亮建筑；产地角标「待运 N 担」互补 |
| 切片表现 | **walker 系统**：背货 = 小点+物资色包裹（产地→城门→仓库两段折线）；小点**按职业着色**——农绿、伐木棕、矿灰、商人黄（占位可调） |
| 正式版 | 必须实现可见的背负物资 NPC 走去粮仓/货仓（用户明确要求）；**田间储物仓**（二级仓储：产地→田间仓近距高频 → 城内仓远距大批量，把运输税变成可投资降低）已挂档正式版专题，切片不做 |

## 7. 宵禁与商人作息（v0.2 新增）

商人一日时间轴：

```
白天  城内做生意（生钱/商税）
下午  出城进货
傍晚  回城——回城时间随机，可能在宵禁前，也可能在宵禁后
夜间  城门宵禁，默认关闭（绝对安全，无任何事件）
```

> **地图与视野（v0.3 定案）**：玩家可见范围 = 主城 + 城外田区（+ 烽燧驱散区），往外即**战争迷雾**，迷雾外不远就是地图边界（地图不大）。商人"出城进货"= **走入迷雾的抽象动作**，无货源实体，进迷雾即视为进货。

| 规则 | 内容 |
|---|---|
| 宵禁政策（v0.4 三态） | 城门口设**持久政策开关**：**常开**（商队每晚自动入城 + 夜赌事件）/ **常闭**（商队夜宿驿站，城内绝对安全）/ **每晚询问**（默认；弹窗内提示"可在城门设置常开/常闭，不再每晚询问"） |
| 驿站（v0.4 新增） | 城外**固有设施**（免建造、不占格、不可破坏）：宵禁不放行/夜闭 → 商人**夜宿驿站** → 次日**商税减半**（误早市，占位 10→5 钱）；骚扰日商人滞留驿站**照常可被杀**（驿站防匪不防军） |
| ~~滞留赌命~~ | v0.4 删除"不放行每夜 15% 死亡"——由驿站税减半 + 骚扰日可杀替代（纯 RNG 减员太挫败） |
| 夜赌事件 | 仅常开/放行时触发：**偷盗**（-钱-粮）/ **失火**（烧建筑，**豁免粮仓/货仓**）；关门绝对安全 |
| 望火楼 | 科技树解锁建筑；装备后开门事件概率归零 |
| 商税结算（v0.3 定案） | 商铺**每日向总库交税，直接充盈库房、不走运输线**（城内流程简化）。占位税率：坊 5 钱/日、肆 12 钱/日；声望加成另算（见 03 §3.4）；夜宿驿站次日减半（v0.4） |
| 商人补员（v0.3 定案） | 每建成一座商业建筑，从闲民抽 1 人任商人；商人死亡自动从闲民池再补，**池空则商铺停摆无税** |

## 8. 岗位效率曲线（沿用，核心机制）

设建筑岗位上限为 N，在岗人数为 x：

- `x ≤ N`：效率 = (x / N) × 100%
- `x > N`：效率 = max(0, 100% − k × (x − N) / N × 100%)，k ≈ 2~3 待调

设计意图：缺员有代价、超员有惩罚、每条产线都缺人 → 资源分配张力贯穿全局。

> 候选简化（用户曾提出，待裁决）：改「Y/人 + 满员奖 X」公式，心算更友好。候选数值：农田 Y2/X2、伐木 Y2/X0、矿洞 Y1/X2、工匠坊 Y1/X0（满岗总量 12/8/6/3）。

## 9. 与关隘系统的联动钩子（沿用）

- 矿点位置固定且依地形分布 → 矿是否好采成为关卡变量
- 关隘地势/天气/地貌影响产线效率（寒冷关隘粮产下降等）
- 田块数量/质量随关隘变化
