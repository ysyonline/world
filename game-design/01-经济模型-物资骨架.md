## 1. 设计总纲：一人口三约束

经济系统的本质是 **人口驱动的资源产消闭环**：

- **人口** 是隐藏核心资源（总闸门）：每人每日消耗粮；人口填充各建筑岗位
- **三约束**：粮养人（饿不起）→ 人上岗（岗位有限）→ 岗驱动产线（四条产线抢人）
- 玩家核心决策：有限的人口，分配给哪条产线？田种粮还是种丝？

### 3.1 田块二选一（核心决策点①）

- 同一田块只能选择种农田（产粮）或桑田（产丝）
- 粮 = 生存底线，丝 = 发展上限 → 玩家在「活下去」与「富起来」之间做分配
- 换种是否允许、换种成本（时间/资源）待讨论

### 3.2 岗位效率曲线（核心机制）

设建筑岗位上限为 N，在岗人数为 x：

- `x ≤ N`：效率随人数上升，满岗（x = N）达到 100%
- `x > N`：超员后效率**急剧下降**（拥挤惩罚）

结构公式（系数待原型验证）：

```
x ≤ N : 效率 = (x / N) × 100%
x > N : 效率 = max(0, 100% − k × (x − N) / N × 100%)   k ≈ 2~3 待调
```

设计意图：
- 缺员有代价 → 逼玩家合理分配人口
- 超员有惩罚 → 防止「无脑堆人」，人口始终稀缺
- 每条产线都缺人 → 资源分配张力贯穿全局

### 3.3 货币与繁荣度（已确认加入）

**钱**是独立于物资的货币层：

| 维度 | 规则 |
|---|---|
| 钱的用途 | ① 造建筑 ② 发军饷 ③ 造防御工事 —— 经济建设与军事建设抢同一个钱袋子 |
| 钱的来源 | **待设计**。候选（有史实依据）：朝廷按周期拨付军资、互市贸易（丝/粮外销换钱）、屯田余粮出售 |
| 繁荣度 | **用钱衡量**关内建设水平；**繁荣度每次提升 → 声望+**（联动 03 文档） |

设计意图：
- 钱是"通用转换器"：物资是专项的（木只能干木的事），钱是万能的 → 玩家在"攒钱搞建设"与"烧钱养军队"之间做第二层分配
- 繁荣度 → 声望 → 人口流入，形成"经济搞得好 → 人越来越多 → 产线更强"的正循环；反之穷兵黩武则经济空心化

## 4. 与关隘系统的联动钩子（预留）

- **矿点位置固定且依地形分布** → 每个关隘矿点不同，矿是否好采成为关卡变量
- 关隘的地势/天气/地貌可影响产线效率（如：寒冷关隘粮产下降、衣需求上升）
- 田块数量/质量随关隘变化 → 桑田占比策略因关而异
