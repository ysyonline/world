## 1. 一句话体验

玩家在攻城大限倒计时下经营一座长城关隘：种田伐木采矿、**看着工人把城外物资一担担背回城**、盖民房接住流民、开坊收商税、接皇帝任务攒钱、养三营兵；骚扰期在**开门（赌铁骑不入城）/ 关门（锁死城外自己人）**之间抉择；总攻日在自动结算的战局中抓住**倒火油、出城拆器械、堵门洞**三个决策窗口——顶住则胜，声望归零或匈奴涌入则败，并看得懂自己输在哪。

单局时长目标：20~30 分钟（待原型验证）。

## 4. 核心循环（一个游戏日）

```
实时循环：产出秒级累积于产地 → 自运背回入库（walker 可见）→ 账本田鸡实时预估
日切结算（人口耗粮 → 军粮军饷 → 商税直入库（驿站过夜减半）→ 欠缴/饥荒判定）
  → 经营决策（建/拆建筑、岗位调配、民房扩建、收保撤回）
  → 军事决策（三营送训/提前出营、布防墙段、放檑木/火油/重弩位）
  → 看倒计时与预警（烽燧：骚扰波明日到；饥荒/欠饷红灯）
  → 骚扰波日：战前选开门/关门 → 自动结算 + 决策点 → 战报
  → 皇帝任务：接到 → 接/不接 → 到期判定
  → 夜晚：宵禁政策生效（常开/常闭/询问）→ 开门则夜赌事件判定
  → 战后处置（俘虏二选一）→ 进入下一日
```

平时全力种田运输，骚扰日拷问开门/关门与收保决策，总攻日检验全部积累——三层节奏对应 02 §4。

## 5. 战中决策点（方案 C 核心，全战斗 ≤3 个）

| # | 触发条件 | 玩家选项 | 结算影响 |
|---|---|---|---|
| 1 | 敌器械（冲车/井阑）进入火油射程 | 倒火油？（耗火油库存 1 份） | 倒 = 器械点燃（概率摧毁/持续毁伤）；不倒 = 保留库存 |
| 2 | 敌器械存活且压制墙段 | 出城拆除？（派步兵/工兵） | 出 = 器械大概率拆除，出城部队按当场铁骑存活比例折损；不出 = 器械持续输出 |
| 3 | 任一门破 | 步兵堵门洞？ | 堵 = 门洞堵住，战斗继续（最后窗口）；不堵 = 匈奴涌入 → 立即判败 |

> 纪律：决策点全战斗不超过 3 个，不加第四个——防止滑向全程微操，保住切片纪律。

## 6. 玩家交互清单（切片内全部操作）

**经营面**
- 点选网格地块建造：关内（工匠坊/兵营/市坊/粮仓/货仓/民房）、城外（粟田/伐木场/矿洞/烽燧），按 01 §4.3 造价扣钱/木/土/铁
- 每个建筑 +/- 在岗人口（超员效率急降提示）；**住房软上限**：超出人口为闲民不可派工（红字）
- **收保**按钮：一键撤城外平民——走路回城变闲民（walker 可见），复工走回
- **运输线列表**：一条线 = 一个产地→对应仓库；显示在运物资 / 今日累计入库 / 状态（运输中 / 待运 N 担 / 收保停产 / 无人上岗）；点行高亮建筑；产地角标「待运 N 担」
- **账本田鸡**：昨日实结（资源×来源分列）+ 今日预估 + 负额诊断；HUD 常驻折叠条
- **城门政策三态开关**：常开 / 常闭 / 每晚询问（默认询问）
- 资源面板：粮/木/土/铁/钱/人口（`民 32/30`：白总数/绿在岗/红闲民）/兵（分三兵种）/声望/政治点 + 每日耗粮速率

**军事面**
- 兵营：三营送训（训练进度可见）、提前出营（明示熟练度折算）
- 发军粮军饷或欠缴（明示逃兵/兵变风险）
- 战前布防：步/弓/工分配墙段；檑木/火油/重弩配置到墙段
- 骚扰波战前：**开门 / 关门**二选一（明示两端风险）

**战中与战后**
- 战斗自动结算，三个决策点暂停弹选（§5）；不做其他战中操作（切片纪律）
- 战报面板：分列各兵种歼敌/战死/逃兵/俘虏 + 被抢掠量
- 俘虏二选一：杀（声望↓）/ 关押（赌转化）

**事件与结局**
- 皇帝任务：接/拒弹窗（缴粮或缴钱，到期判定）
- 宵禁：按政策生效（询问态每晚弹窗，可切常开/常闭免打扰）；开门触发夜赌事件（偷盗/失火，豁免两仓）；驿站夜宿次日税减半
- 饥荒预警（黄灯/红灯）、双失败结算画面（声望归零 / 匈奴涌入），各自给出原因复盘

## 8. 切片整体验收标准

1. 从零开局可连续游玩至任一结局触发，无死档、无卡死
2. 败局两路可复现：故意弃防 → 匈奴涌入败；故意杀俘+闹饥荒 → 声望归零即时败
3. 正常经营可守过总攻获胜，且胜利路径必须经过「种田养军 vs 穷兵黩武」与「开门赌 vs 关门锁」两重取舍
4. 运输线状态可读：列表/角标可见每条线在运什么、运了多少；骚扰期收保与否影响平民伤亡（收保 = 保人）
5. 三个战中决策点各自可触发且改变战果
6. 所有数值占位均在代码内集中配置（一处调参，全局生效），保留「待原型验证」标注
7. 人口软上限生效：流民超住房来投 → 红字闲民不可派工；造民房后立即可派
8. 宵禁三态各自可复现：常开有夜赌、常闭驿站税减半、询问每晚弹窗（可切换免打扰）
9. 账本田鸡：昨日实结与日志流水一致；今日预估随配置调整实时变化；负额资源有诊断
10. walker 可见：背货（职业着色+包裹）与收保撤离肉眼可见，产者自运无"幽灵运输"
