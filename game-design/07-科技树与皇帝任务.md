## 1. 科技树：文武双线解锁

```
官职线：完成皇帝的任务 → 政治点数 → 升官 → 解锁「政治经济类」科技
军衔线：打仗           → 战功     → 升军衔 → 解锁「军事类」科技
```

| 线 | 积累方式 | 解锁方向 | 候选科技（占位） |
|---|---|---|---|
| 官职（文） | 皇帝任务 → 政治点 | 经济/治理 | 酒肆·茶肆·布肆（坊→肆升级）、望火楼、农时改良、商税加成 |
| 军衔（武） | 战斗 → 战功 | 军事/城防 | 探马（预警强化）、城防材质（夯土→三合土→砖包城）、齐射强化、老兵训练 |

设计意图：
- **玩法分流器**：种田流刷文官线、好战流走军衔线；两线互相馋（文官想要城防加固、武将想要产量加成）→ 逼玩家文武双修或接受偏科
- 科技树整体结构后续专项讨论（用户挂账），本文只定双线骨架与已知节点

### 待确认

## 2. 皇帝任务

### 2.1 核心规则（已定案）

| 规则 | 内容 |
|---|---|
| 发放 | 每个关卡中，**每隔一段时间**收到一件朝廷任务（频率数值待定稿） |
| 选择 | 玩家可**接受或拒绝**；**拒绝无惩罚** |
| 完成 | 奖励**政治点数** |
| 失败 | 接受后未完成 → **有惩罚**（形式待定，候选：政治点倒扣 + 声望小降） |

### 2.2 任务类型（候选池）

| 类型 | 内容 | 张力 |
|---|---|---|
| 输粮 | 上缴 X 粮 | 与人口口粮直接竞争 |
| 缴税 | 上缴 X 钱 | 与建设/军饷竞争 |
| 上缴军备 | 上缴 X 檑木/重弩等器械 | 交出去 = 自己的城防变弱 |

### 2.3 史据包装

- **入粟拜爵**：晁错《论贵粟疏》"入粟县官，得以拜爵"——缴粮换政治点（爵位）的正史原型
- **上计制度**：汉代边郡每年向朝廷上计（报户口、垦田、钱粮、兵器账目），朝廷据此考核——"定期收到任务"即游戏化的上计考核

### 2.4 待设计（挂账）

1. 任务发放频率、是否可同时挂多任务/积压
2. 失败惩罚的具体形式与数值
3. 任务难度是否随玩家产能/关卡进度缩放
4. 连续完成/连续失败的连锁效果（朝廷信任度？）
