## 1. 一句话体验

玩家在攻城大限倒计时下经营一座长城关隘：分配有限人口种田、伐木、采矿、造武器，养军练兵、发粮发饷，顶住 2~3 波骚扰后打赢总攻——或者城破 / 声望崩盘而败，并看得懂自己输在哪。

单局时长目标：20~30 分钟（待原型验证）。

## 2. 技术方案（已确认）

| 项目 | 决策 |
|---|---|
| 维度 | **2D**（俯视网格：关内经营区 + 城墙防线段，敌从关外来） |
| 形态 | **单文件 HTML + Canvas + 原生 JS**，零依赖，浏览器即开即玩 |
| 理由 | 切片验证玩法闭环与数值咬合，不验证渲染；规则高频调参期，技术越轻迭代越快 |
| 正式版预留 | 引擎选型（Godot 等）切片验证通过后再评估，本切片不背引擎成本 |

## 4. 核心循环（一个游戏日）

```
收结算（昨日产出入库、人口耗粮、军粮军饷扣减、欠缴判定）
  → 经营决策（建/拆建筑、分配岗位、种田 or 产线调配）
  → 军事决策（送训 / 提前征召、布防墙段、放檑木位）
  → 看倒计时与预警（距总攻 x 天；饥荒/欠饷红灯）
  → 波次日：守城战自动结算 → 战报（伤亡/逃兵/俘虏）
  → 战后处置（俘虏二选一）→ 进入下一日
```

平时全力种田，骚扰日拷问战备余量，总攻日检验全部积累——三层节奏对应 02 §3。

## 5. 玩家交互清单（切片内全部操作）

**经营面**
- 点选网格地块 → 建造农田/伐木场/矿洞（仅固定矿点）/铁匠铺（耗钱耗木）
- 对每个建筑 +/- 在岗人口，实时看到超员效率骤降提示
- 查看资源面板：粮/木/矿/武器/钱/人口/兵/声望 + 每日耗粮速率

**军事面**
- 军营：把普通人送入训练（显示训练进度），或提前征召（明示熟练度/士气 debuff）
- 发军粮军饷 或 选择欠缴（明示逃兵/兵变风险）
- 战前布防：把弓箭兵/近战兵分配到各城墙段；在墙段放置檑木

**战斗与战后**
- 攻城倒计时全程可见；战斗自动结算，**不做战中实时操作**（切片纪律）
- 战报面板：歼敌/战死/逃兵/俘虏数
- 俘虏二选一：杀（声望↓）/ 关押（赌转化）

**事件与结局**
- 饥荒预警（动态阈值逼近时黄灯、触发后红灯）
- 双失败结算画面：城破 或 声望破底线，各自给出原因复盘

## 7. 切片整体验收标准

1. 从零开局可连续游玩至任一结局触发，无死档、无卡死
2. 双失败条件各自可复现：故意弃防→城破；故意杀俘+闹饥荒→声望破底线
3. 正常经营可守过总攻获胜，且胜利路径必须经过「种田养军 vs 穷兵黩武」的取舍
4. 所有数值占位均在代码内集中配置（一处调参，全局生效），并保留「待原型验证」标注
